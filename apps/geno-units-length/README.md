# geno-units-length

Length unit converter in [Geno](https://github.com/davidiach/geno-lang).

## Install

```bash
pip install geno-lang
```

## Test

```bash
geno test Main.geno
```

## Run

```bash
geno run Main.geno
```

## API

- `meters_to_feet(meters) -> Float`
- `feet_to_meters(feet) -> Float`
