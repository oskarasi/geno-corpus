# geno-discount

Discount calculator in [Geno](https://github.com/davidiach/geno-lang).

## Install

```bash
pip install geno-lang
```

## Test

```bash
geno test Main.geno
```

## Run

```bash
geno run Main.geno
```

## API

- `discount_amount_cents(price, percent_off) -> Int`
- `price_after_discount_cents(price, percent_off) -> Int`
