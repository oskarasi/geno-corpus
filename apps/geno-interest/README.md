# geno-interest

Simple interest in [Geno](https://github.com/davidiach/geno-lang).

## Install

```bash
pip install geno-lang
```

## Test

```bash
geno test Main.geno
```

## Run

```bash
geno run Main.geno
```

## API

- `simple_interest_cents(principal, rate, time) -> Int`
- `amount_cents(principal, rate, time) -> Int`
