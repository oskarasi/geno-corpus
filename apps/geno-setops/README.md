# geno-setops

Set union/intersect/diff in Geno, written in [Geno](https://github.com/davidiach/geno-lang).

## Install

```bash
pip install geno-lang
```

## Test

```bash
geno test Main.geno
```

## Run

```bash
geno run Main.geno
```

## API

See `Main.geno` for `Set union/intersect/diff` helpers and examples.
