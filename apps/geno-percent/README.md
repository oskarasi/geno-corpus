# geno-percent

Percentage helpers in [Geno](https://github.com/davidiach/geno-lang).

## Install

```bash
pip install geno-lang
```

## Test

```bash
geno test Main.geno
```

## Run

```bash
geno run Main.geno
```

## API

- `percent_of(percent, whole) -> Float`
- `what_percent(part, whole) -> Result[Float, String]`
