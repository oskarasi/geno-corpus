# geno-pluralize

English pluralize helper in Geno, written in [Geno](https://github.com/davidiach/geno-lang).

## Install

```bash
pip install geno-lang
```

## Test

```bash
geno test Main.geno
```

## Run

```bash
geno run Main.geno
```

## API

See `Main.geno` for `English pluralize helper` helpers and examples.
