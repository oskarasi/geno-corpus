# geno-tax

Sales tax calculator in [Geno](https://github.com/davidiach/geno-lang).

## Install

```bash
pip install geno-lang
```

## Test

```bash
geno test Main.geno
```

## Run

```bash
geno run Main.geno
```

## API

- `tax_cents(price, tax_percent) -> Int`
- `price_with_tax_cents(price, tax_percent) -> Int`
